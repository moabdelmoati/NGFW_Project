# 🛡️ NGFW Browser Extension

امتداد المتصفح لاعتراض وفحص الروابط المشبوهة في الوقت الفعلي.

## 📋 المميزات

- ✅ اعتراض تلقائي لجميع الروابط عند فتحها
- ✅ فحص فوري باستخدام ML و DPI و Signatures
- ✅ حظر الروابط المشبوهة تلقائياً
- ✅ إشعارات عند حظر رابط
- ✅ واجهة بسيطة لفحص الروابط يدوياً
- ✅ إحصائيات عن الروابط المحظورة

## 🚀 التثبيت

### Chrome / Edge

1. افتح Chrome واذهب إلى `chrome://extensions/`
2. فعّل "Developer mode" (وضع المطور)
3. اضغط على "Load unpacked"
4. اختر مجلد `browser-extension`
5. تم التثبيت! 🎉

### Firefox

1. افتح Firefox واذهب إلى `about:debugging`
2. اضغط على "This Firefox"
3. اضغط على "Load Temporary Add-on"
4. اختر ملف `manifest.json` من مجلد `browser-extension`
5. تم التثبيت! 🎉

## ⚙️ الإعدادات

- **تفعيل/تعطيل الحماية**: استخدم المفتاح في popup
- **فحص رابط يدوياً**: أدخل الرابط واضغط "فحص الرابط"
- **عرض الإحصائيات**: عدد الروابط المحظورة يظهر في popup

## 🔧 المتطلبات

- يجب أن يكون NGFW Backend يعمل على `http://127.0.0.1:5000`
- يجب تفعيل CORS في Backend (موجود بالفعل)

## 📝 ملاحظات

- الروابط المفحوصة يتم حفظها في cache لمدة 5 دقائق
- الروابط المحظورة يتم حفظها محلياً لتجنب إعادة الفحص
- في حالة فشل الاتصال بالـ Backend، سيتم السماح بالوصول (fail-open)

## 🐛 استكشاف الأخطاء

إذا لم يعمل الامتداد:
1. تأكد أن Backend يعمل على `http://127.0.0.1:5000`
2. افتح Console في Developer Tools وابحث عن أخطاء
3. تأكد من تفعيل "Developer mode"
