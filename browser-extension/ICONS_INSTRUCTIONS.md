# 🖼️ تعليمات الأيقونات

لإكمال تثبيت Browser Extension، تحتاج إلى إضافة أيقونات.

## الطريقة السريعة

1. افتح أي محرر صور (Paint, GIMP, Photoshop)
2. أنشئ صور بحجم:
   - 16x16 pixels → `icon16.png`
   - 48x48 pixels → `icon48.png`
   - 128x128 pixels → `icon128.png`
3. استخدم أيقونة درع أمني 🛡️ أو أي رمز أمني
4. احفظ الملفات في مجلد `browser-extension`

## أو استخدم أيقونات جاهزة

يمكنك استخدام أيقونات من:
- [Flaticon](https://www.flaticon.com) - ابحث عن "shield" أو "security"
- [Icons8](https://icons8.com) - أيقونات مجانية
- [Font Awesome](https://fontawesome.com) - أيقونات SVG

## أو استخدم نص بديل مؤقت

يمكنك تعديل `manifest.json` وإزالة قسم `icons` مؤقتاً للتجربة.

## ملاحظة

بدون الأيقونات، سيعمل الامتداد لكن قد تظهر رسالة تحذير في المتصفح. هذا لا يؤثر على الوظيفة.
